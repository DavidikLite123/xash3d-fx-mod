# Hash Online · веб-портал

Автономный фронтенд (без сборщиков; JSZip лежит локально в `vendor/`) для игрового
портала **Hash Online** — браузерной оболочки движка **«Ха-кэш»**.
Кроссплатформенно: десктопные и мобильные браузеры.

## Файлы

| Файл        | Назначение |
|-------------|------------|
| `index.html` | Разметка: заставка, главное меню, контейнеры модалок и тостов |
| `style.css`  | Тёмная неоновая тема, GPU-анимации (transform/opacity), адаптив, системные шрифтовые стеки |
| `app.js`     | Вся логика: экраны, карточки, динамические модалки, умная распаковка .zip, boot-последовательность «Ха-кэш» |
| `vendor/jszip.min.js` | Локальная копия JSZip 3.10.1 — распаковка мобильного кэша без внешних CDN |

## Ключевые возможности

1. **Заставка** — неоновый логотип, кнопка `[ НАЧАТЬ ]` (Enter тоже работает) → кроссфейд в меню.
2. **Меню** — grid карточек `Counter-Strike 1.6` и `Half-Life` + плитка `[ ЕЩЁ ]`,
   раскрывающая блок: `Модифицированная CS 1.6`, `Модифицированная Half-Life`,
   `Source Engine Port` (клик → тост «Порт движка Source в разработке, скоро!»).
3. **Модальное окно игры** — у обычной игры одна зона `[ Загрузить файлы игры ]`,
   у модифицированной динамически появляется вторая — `[ Загрузить файлы мода ]`
   (контент мода накладывается в памяти поверх оригинального кэша).
   `[ ЗАПУСТИТЬ ]` активна только при заполненных зонах.
4. **Умная распаковка .zip** — зоны принимают папку перетаскиванием (рекурсивный
   обход), выбором через диалог, либо `.zip` архив любого размера. При распаковке
   показывается «Распаковка архива: X%…», сканируется ВСЁ дерево папок архива,
   отыскивается целевая папка (`cstrike` / `valve`), её содержимое сохраняется,
   остальное автоматически игнорируется и вычищается из памяти. Если целевая
   папка не найдена — ошибка: «Ошибка: В архиве не найдена папка с файлами игры…».
5. **Подсказки «где взять файлы»** — под зоной игры блок
   «🔍 Нет файлов игры? Скачать готовый мобильный кэш», под зоной мода —
   «🌐 Каталог модов». Панели раскрываются плавно, ведут только на легальные
   источники (официальные страницы игр, инструкция сборки кэша из своей копии,
   бесплатные моды с ModDB / GameBanana / RunThinkShootLive), все ссылки
   открываются в новой вкладке (`target="_blank"`).
6. **Тишина в эфире** — синтезированных звуков интерфейса нет. Звук можно
   подключить позже штатными HTML5 `<audio>`-тегами из реальных файлов.

## Запуск

```bash
cd web-portal
python3 -m http.server 8080 --bind 0.0.0.0
# открыть http://localhost:8080
```
