# Hash Online · веб-портал

Автономный фронтенд + локальное JS-ядро для игрового портала **Hash Online** —
браузерной оболочки движка **«Ха-кэш»**. Кроссплатформенно: десктопные и
мобильные браузеры, Linux в том числе (см. раздел про инпуты). Без внешних CDN.

## Структура

| Путь | Назначение |
|------|------------|
| `index.html` | Три экрана: заставка, меню, полноэкранный игровой холст |
| `style.css`  | Неоновая тема, GPU-анимации, HUD холста, адаптив |
| `app.js`     | UI-логика + боевой запуск: монтирование VFS, Module, boot, игровая сессия |
| `engine/vfs.js`    | Emscripten-FS-совместимая виртуальная ФС (байты в памяти, symlink) |
| `engine/module.js` | Фабрика конфигурации `Module` + построитель argv по ТЗ |
| `engine/xash.js`   | Локальное ядро: boot с run-dependencies, индексация VFS, CRC32, liblist.gam, WebGL-рендер |
| `vendor/jszip.min.js` | Локальная JSZip 3.10.1 — умная распаковка .zip |
| `tests/run-tests.js`  | 19 групп проверок: `node tests/run-tests.js` |

## Пайплайн запуска (честный, без симуляций)

1. Пользователь выбирает карточку → модальное окно: папка или `.zip`
   (отдельные Linux-safe инпуты `webkitdirectory directory` и `accept=".zip"`,
   плюс полноценный drag&drop через `event.dataTransfer`).
2. `.zip` любого размера распаковывается с прогрессом «Распаковка архива: X%…»,
   целевая папка (`cstrike`/`valve`) ищется по ВСЕМУ дереву архива, остальное
   игнорируется и вычищается из памяти.
3. `[ ЗАПУСТИТЬ ]` → boot-окно: файлы **побайтово** пишутся в VFS:
   `/xash/cstrike/`, `/xash/valve/`; мод накладывается поверх в ту же
   директорию (счётчик перезаписей — реальный), каталог мода получает
   symlink-дерево и `liblist.gam` для `-game`.
4. Создаётся Emscripten-совместимый `Module` с `arguments` по ТЗ
   (`["-dev","3","-log"]`, `["-game","cstrike",...]`, `-game <папка_мода>`).
5. Ядро выполняет реальный boot: валидация VFS, индексация ресурсов,
   CRC32-скан, разбор `liblist.gam`. `monitorRunDependencies` гонит честные
   проценты в прогресс-бар.
6. `onRuntimeInitialized` → модалка скрывается, `<canvas>` разворачивается
   на весь экран, получает фокус; работает HUD: FPS-метр, захват мыши
   (Pointer Lock), полноэкранный режим, выход в меню.

## Переход на официальный wasm

Контракты уже «взрослые»: замените `engine/xash.js` на официальный glue
и положите рядом `xash.wasm` (путь уже прописан в `Module.locateFile`) —
`app.js`, `module.js`, `vfs.js` менять не потребуется.

## Запуск

```bash
cd web-portal
python3 -m http.server 8080 --bind 0.0.0.0
# открыть http://localhost:8080
```

Тесты: `node tests/run-tests.js`
