# Hash Online · веб-портал

Чистый фронтенд (без сборщиков и зависимостей) для игрового портала **Hash Online** —
браузерной оболочки движка «Ха-кэш» (модифицированный Xash3D / GoldSrc).
Целевая платформа: **Chrome ARM64 · Raspberry Pi 5**.

## Файлы

| Файл        | Назначение |
|-------------|------------|
| `index.html` | Разметка: заставка, главное меню, контейнеры модалок и тостов |
| `style.css`  | Тёмная неоновая тема, GPU-анимации (transform/opacity), адаптив |
| `app.js`     | Вся логика: экраны, карточки, динамические модалки, загрузка папок (input `webkitdirectory` + drag&drop с рекурсивным обходом), блокировка `[ ЗАПУСТИТЬ ]`, имитация boot-последовательности «Ха-кэш» с прогресс-баром и живым логом |

## Запуск

Нужен любой статический HTTP-сервер (выбор директории через `<input webkitdirectory>`
работает и с `file://`, но сервер — надёжнее):

```bash
cd web-portal
python3 -m http.server 8080 --bind 0.0.0.0
# открыть http://localhost:8080
```

## Как это устроено

1. **Заставка** — неоновый логотип, кнопка `[ НАЧАТЬ ]` (Enter тоже работает) → кроссфейд в меню.
2. **Меню** — grid карточек `Counter-Strike 1.6` и `Half-Life` + плитка `[ ЕЩЁ ]`,
   раскрывающая блок: `Модифицированная CS 1.6`, `Модифицированная Half-Life`,
   `Source Engine Port` (клик → тост «Порт движка Source в разработке, скоро!»).
3. **Модальное окно игры** — у обычной игры одна зона `[ Загрузить файлы игры ]`,
   у модифицированной динамически появляется вторая — `[ Загрузить файлы мода ]`.
   Выбранные папки реально сканируются (количество/размер/типы файлов),
   `[ ЗАПУСТИТЬ ]` активна только при заполненных зонах.
4. **Boot-окно «Ха-кэш»** — анимированный прогресс-бар, терминальный лог
   со статистикой реально выбранных файлов (WAD/MDL/BSP/SPR/WAV), кнопка `ОТМЕНА`.

Состояние загруженных библиотек хранится в памяти сессии и отражается на карточках
(статусы «файлы не загружены / ждём мод / готов к запуску»).
