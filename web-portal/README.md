# Hash Online · веб-портал

Автономный фронтенд + кит совместимости для игрового портала **Hash Online** —
браузерной оболочки движка **«Ха-кэш»**. Кроссплатформенно: десктопные и
мобильные браузеры, Linux в том числе (см. жёсткий фикс инпутов ниже).
Работает **полностью офлайн**: внешних CDN нет, ядро — локальное.

## Структура

| Путь | Назначение |
|------|------------|
| `index.html` | Три экрана: заставка, меню, полноэкранный игровой холст `<canvas id="canvas">` |
| `style.css`  | Неоновая тема, GPU-анимации, HUD холста, 3D-лейблы ресурсов, адаптив |
| `app.js`     | UI + боевой запуск: распаковка, реальный glue, монтирование в `Module.FS`, сессия |
| `engine/xash.js` | Кит v1.4: `var Module + Module.FS`-эмулятор, ленивый загрузчик настоящего glue, WebGL-рендер-цикл |
| `dev-server.js` | Автономный сервер (ноль зависимостей): COOP/COEP, MIME, отдаёт корневые `xash.js`/`server.js` |
| `vendor/jszip.min.js` | Локальная JSZip 3.10.1 — умная распаковка .zip |
| `tests/run-tests.js` | 73 проверки (Node): `node tests/run-tests.js` |
| `tests/smoke-real-engine.js` | Смоук-тест: настоящий `/xash.js` — live runtime-init + запись/чтение `Module.FS` |

Настоящее ядро — в корне репозитория: `xash.js` (клиентский glue asm.js,
~7 МБ) и `server.js` (серверный модуль для Worker-потока, ~3 МБ).
`dev-server.js` отдаёт их по адресам `/xash.js` и `/server.js` с корня сайта —
свободно `web-portal/` в «грязное» место не добавляем.

## ЖЁСТКИЙ ФИКС ИНПУТОВ (Linux)

Атрибуты `webkitdirectory`/`directory` удалены **полностью, во всех
модальных окнах** (HL, CS 1.6, моды) — именно они блокировали проводник
Linux при выборе архивов. Формат инпута — строго **одиночный .zip**:

```html
<input type="file" class="game-zip-input" accept=".zip">
```

Параллельно работает большая Drop Zone: перетаскивание `.zip` любого
размера перехватывается через `e.dataTransfer.files` (и папки вдогонку —
рекурсивным FileSystemEntry-обходом).

## Умная распаковка .zip

1. Архив читается целиком в память локальной JSZip (офлайн).
2. Прогресс на неоновом баре: «Распаковка: X%...» — проценты считаются
   по реальным байтам каждой записи.
3. Целевая папка ищется по ВСЕМУ дереву любой глубины: `cstrike/`
   для CS 1.6, `valve/` для Half-Life (модовые архивы — без фильтра).
   Посторонние деревья и мусор (`__MACOSX`, `.DS_Store`) вычищаются.
4. Если целевая папка не найдена: «Ошибка: В архиве не найдена папка
   с файлами игры. Убедитесь, что загружаете правильный мобильный кэш».

## Автономный запуск (без xash.html.mem)

1. `[ ЗАПУСТИТЬ ]` (активна только после успешной распаковки правильных
   архивов) открывает boot-окно с терминалом и честным прогрессом.
2. Кит уже объявил глобальный `var Module` (контракт Emscripten);
   app.js заполняет `Module['arguments']` по чек-листу:
   HL → `["-dev","3","-log"]`, CS → `["-game","cstrike","-dev","3","-log"]`,
   моды → `["-game","<папка_мода>",...]`.
3. **Настоящий glue** лениво грузится (`<script src="/xash.js">`):
   `noInitialRun:true` + `memoryInitializerRequest` (нулевой буфер вместо
   отсутствующего `xash.html.mem`) → runtime-init БЕЗ сети и ошибок,
   `monitorRunDependencies` → настоящие проценты. `main()` движка не
   запускается (бинарного образа памяти пока нет) — зато живёт настоящий
   `Module.FS` (MEMFS Emscripten). Если glue по какой-то причине
   недоступен — плавно переходим на локальный FS-эмулятор того же интерфейса.
4. Распакованные файлы **побайтово** монтируются:
   база → `/xash/cstrike/` или `/xash/valve/` через
   `FS.createDataFile(parent, name, bytes, true, true, false)`
   (с гарантированным `FS.mkdirTree` родителей); мод — поверх в ту же
   директорию (счётчик перезаписей — реальный), каталог мода получает
   symlink-дерево и сгенерированный `liblist.gam`.
5. Меню плавно сворачивается, `<canvas id="canvas">` разворачивается
   на весь экран, получает фокус → автономный **тихий** WebGL 3D-цикл:
   орбиты-точки имён реальных файлов FS, каркасная сетка-пол,
   Pointer Lock (yaw/pitch с инерцией), дрейф камеры без захвата,
   CPU-проецируемые неоновые лейблы ресурсов. Звука нет — никаких
   синтезированных peep/beep.
6. HUD: FPS-метр, захват мыши, полный экран, выход в меню.

## Проверки

- `node --check` всех скриптов.
- 73 юнит-проверки: распаковка, DnD-логика, Module.FS кита,
  `fsWalkFiles` поверх реального MEMFS-интерфейса, жёсткий Linux-фикс
  (регэкспы по исходникам), смоук реального `/xash.js` с round-trip
  байтов в настоящей MEMFS.
- Аудит: брендов нет, звукового синтеза нет, CDN нет.

## Запуск

```bash
cd web-portal
node dev-server.js        # $PORT по умолчанию 8080, биндинг 0.0.0.0
# открыть http://localhost:8080
```
