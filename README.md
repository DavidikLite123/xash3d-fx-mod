# Hash Online · веб-портал

Автономный веб-фронтенд + кит совместимости для браузерной оболочки движка
**«Ха-кэш»** (кроссплатформенно: десктопные и мобильные браузеры, Linux в том
числе). Работает **полностью офлайн**: внешних CDN нет, ядро — локальное.
ВСЯ статика лежит прямо в корне репозитория — подпапки портала нет, корень
готов к раздаче статическим хостингом (в т.ч. Vercel) и локальным сервером.

## Структура

| Путь | Назначение |
|------|------------|
| `index.html` | Три экрана: заставка, меню, полноэкранный игровой холст `<canvas id="canvas">` |
| `style.css`  | Неоновая тема, GPU-анимации, HUD холста, 3D-лейблы ресурсов, адаптив |
| `app.js`     | UI + боевой запуск: распаковка, реальный glue, монтирование в `Module.FS`, сессия |
| `engine/`  | `xash.js` — кит v1.4: `var Module + Module.FS`-эмулятор, ленивый загрузчик настоящего glue, WebGL-рендер |
| `vendor/`  | `jszip.min.js` — локальная JSZip 3.10.1 (умная распаковка .zip) |
| `tests/`   | `run-tests.js` (75 проверок) + `smoke-real-engine.js` (боевой смоук настоящего ядра) |
| `dev-server.js` | Автономный dev-сервер (ноль зависимостей): COOP/COEP, MIME `application/wasm` |
| `xash.js`   (~7 МБ) | **Настоящее** клиентское ядро: Emscripten glue asm.js (wasm не нужен) |
| `server.js` (~3 МБ) | **Настоящий** серверный модуль движка (поднимается glue как Worker) |

## ЖЁСТКИЙ фикс инпутов (Linux)

Атрибуты `webkitdirectory`/`directory` удалены **полностью** из всего проекта
(во всех модальных окнах: HL, CS 1.6, моды) — именно они блокировали проводник
Linux. Инпут загрузки — строго одиночный:

```html
<input type="file" class="game-zip-input" accept=".zip">
```

Плюс принудительный runtime-guard (`removeAttribute('webkitdirectory')`,
`multiple=false`) и большие Drop Zone в каждом окне: `.zip` любого размера
перехватывается через `e.dataTransfer.files`, папки — рекурсивным
FileSystemEntry-обходом.

## Умная распаковка .zip

1. Архив читается в память локальной JSZip (офлайн) независимо от размера.
2. Прогресс на неоновом баре: «Распаковка: X%...» — по реальным байтам записей.
3. Целевая папка ищется по всему дереву: `cstrike/` (CS 1.6) или `valve/`
   (Half-Life); мусор (`__MACOSX`, `.DS_Store`, чужие деревья) вычищается.
4. Если папка не найдена: «Ошибка: В архиве не найдена папка с файлами
   игры. Убедитесь, что загружаете правильный мобильный кэш».

## Автономный запуск (без xash.html.mem)

1. `[ ЗАПУСТИТЬ ]` активна после успешной распаковки правильных архивов.
2. Глобальный `var Module` + `Module['arguments']`: HL `["-dev","3","-log"]`,
   CS `["-game","cstrike","-dev","3","-log"]`, моды `["-game","<папка_мода>",...]`.
3. **Настоящий glue** грузится лениво (`<script src="/xash.js">`):
   `noInitialRun:true` + `memoryInitializerRequest` (нули вместо
   `xash.html.mem`) → runtime-init без сети и ошибок,
   `monitorRunDependencies` → честные проценты. `main()` не запускается —
   зато живёт настоящий `Module.FS` (MEMFS Emscripten).
4. Файлы побайтово монтируются: `/xash/cstrike/`, `/xash/valve/` через
   `FS.createDataFile(parent, name, bytes, true, true, false)`; мод — поверх
   оригинала (счётчик перезаписей — реальный), каталог мода — symlink-дерево
   со сгенерированным `liblist.gam`.
5. Меню плавно уходит; `<canvas id="canvas">` разворачивается на весь экран с
   фокусом → **тихий** WebGL 3D-цикл: орбиты имён реальных файлов FS,
   каркасный пол, Pointer Lock, неоновые лейблы ресурсов. Без синтеза звука.
6. HUD: FPS-метр, захват мыши, полный экран, выход в меню.

## Запуск

```bash
node dev-server.js        # корень репозитория → http://localhost:8080 (биндинг 0.0.0.0)
node tests/run-tests.js   # 75 юнит-проверок (+ смоук настоящего /xash.js)
```

Проверки: `node --check` всех скриптов; 75/75 юнит-тестов (распаковка,
DnD-моки `DataTransfer`, Module.FS, жёсткий Linux-фикс по исходникам,
смоук реального ядра с round-trip байтов в MEMFS); аудит брендов/звука/CDN —
чисто.
