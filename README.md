# Hash Online

Автономный веб-фронтенд и FX-модификация для браузерного движка «Ха-кэш»
(кроссплатформенный web/wasm-порт: десктоп и мобильные устройства).
Адаптивная вёрстка, анимированные экраны, умная распаковка мобильного кэша
(.zip любого размера с фильтрацией целевых папок), реальное побайтовое
монтирование в `Module.FS` и локальное JS-ядро с интерактивным WebGL-рендером.

Быстрый старт:

```bash
cd web-portal
node server.js          # автономный dev-сервер, порт 8080
node tests/run-tests.js # 62 юнит-проверки
```

Подробности — в [`web-portal/`](web-portal/README.md).
