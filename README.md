# Hash Online

Автономный веб-фронтенд и FX-модификация для браузерного движка «Ха-кэш»
(кроссплатформенный web-порт: десктоп и мобильные устройства).
Адаптивная вёрстка, умная распаковка мобильного кэша (.zip любого размера),
побайтовое монтирование в **настоящую `Module.FS` Emscripten** и тихий
интерактивный WebGL 3D-цикл с именами реальных файлов из памяти.

В корне репозитория — оригинальные файлы движка (asm.js glue, wasm не нужен):

| Файл | Назначение |
|------|-----------|
| `xash.js`   (~7 МБ) | Клиентский glue Emscripten: `var Module`, `Module.FS` (MEMFS), SDL-canvas |
| `server.js` (~3 МБ) | Серверный модуль движка (загружается glue как Worker для игрового сервера) |

Быстрый старт:

```bash
cd web-portal
node dev-server.js        # автономный сервер, порт 8080 (отдаёт и корневые xash.js/server.js)
node tests/run-tests.js   # 73 юнит-проверки (+ смоук настоящего ядра)
```

Подробности — в [`web-portal/`](web-portal/README.md).
